# Q2b data

I keep a compact HS2→LFS NAICS bridge (`hs2_naics_bridge.csv`) here for the employment-risk proxy. The Labour Force Survey extract is downloaded on demand into this folder when you run `Q2b.py`.

You can replace the bridge if you prefer a finer concordance. The proxy is illustrative only; HS product codes and NAICS employment do not match one-to-one.
